# Quantium Retail Analytics Case Study
## Customer Analytics, Experimentation & Uplift Testing
### Project Overview
This project analyses **customer purchasing behaviour and store trial performance** for a supermarket chips category. The objective was to **identify opportunities for category growth** by understanding customer segments, product preferences and evaluating the effectiveness of new store layouts.

This project was completed as part of the Quantium Retail Analytics Virtual Experience Program using **R**.

### Business Problem
The Category Manager wanted to answer two key questions:

1. Which customer segments present the greatest opportunity for category growth?
2. Did the new store layouts improve sales performance and customer engagement?

The findings would support the strategic plan for the next six months.

### Dataset
The analysis used:
| Dataset          | Description                                          |
| ---------------- | ---------------------------------------------------- |
| Transaction Data | Customer purchases, products, quantity and sales     |
| Customer Data    | Lifestage and premium customer segmentation          |
| Trial Store Data | Store performance during trial and pre-trial periods |

## Key Findings
### Customer Opportunity
#### Mainstream Young Singles/Couples identified as the highest-value growth segment
One of the largest customer groups
Pay approximately 9% more per unit than other segments
Strong preference for premium brands
Strong preference for larger pack sizes

#### Statistical Validation
| Metric                                  | Result |
| --------------------------------------- | ------ |
| Average Price Per Unit (Target Segment) | $4.04  |
| Average Price Per Unit (Others)         | $3.71  |
| Difference                              | +9%    |
| p-value                                 | <0.001 |

### Product Opportunity
#### Preferred Brands
| Brand    | Affinity Index |
| -------- | -------------- |
| Tyrrells | 1.24           |
| Twisties | 1.23           |
| Kettle   | 1.20           |
| Tostitos | 1.20           |
| OLD      | 1.20           |
| Pringles | 1.19           |


#### Preferred Pack Sizes
| Pack Size | Affinity Index |
| --------- | -------------- |
| 270g      | 1.27           |
| 380g      | 1.26           |
| 330g      | 1.22           |

#### Store Trial Results
| Trial Store | Control Store | Peak Sales Uplift |
| ----------- | ------------- | ----------------- |
| 77          | 233           | +62.3%            |
| 86          | 155           | +31.6%            |
| 88          | 237           | +22.1%            |

#### Outcome
All three trial stores outperformed their matched control stores during the trial period.

## Business Recommendations
#### 1. Target Mainstream Young Singles/Couples
Focus marketing campaigns and promotions on the highest-value customer segment.

#### 2. Promote High-Affinity Brands
Increase visibility of Tyrrells, Twisties, Kettle, Tostitos and other preferred brands.

#### 3. Increase Visibility of Larger Pack Sizes
Prioritise 270g, 330g and 380g products through merchandising and promotions.

#### 4. Expand Successful Trial Layouts
Roll out the new store layout to stores with similar customer profiles.
